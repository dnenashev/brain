# Текущее поведение процесса разработки

Учебный срез Company Brain использует публичные синтетические примеры из задачи `CB13-R2`.

<a id="approved-timeout"></a>
## Таймаут и источник значения

Действующая версия учебного правила `plan-v2` задаёт таймаут по умолчанию `5000` мс. При расхождении с заметкой `note-v1`, где указано `8000` мс, применяется утверждённый план. Результат сопровождается ссылкой на использованную версию (`BDD01`, пп. 2 и 3).

<a id="check-evidence"></a>
## Свидетельства проверок

В пределах запуска повторная доставка результата одной проверки учитывается один раз. При отсутствии результатов доля успешных проверок остаётся неопределённой (`null`), а свидетельства для приёмки отсутствуют (`missing_evidence`). Основание приведено в `BDD02` и `BDD03`, п. 6.

<a id="timeout-permission"></a>
## Полномочия на изменение таймаута

Читатель проекта `P1` не вправе менять утверждённый таймаут. При отказе действует прежнее значение `5000` мс (`BDD04`, пп. 9 и 10).

<a id="feedback-delivery"></a>
## Повторная доставка обратной связи

Очередь учитывает идентификатор доставки. Повторная доставка `feedback-17` оставляет одну карточку (`BDD05`, п. 8).

<a id="handoff-input"></a>
## Полнота передачи

Передача требует цели, артефакта, проверки, границы и источника. При отсутствии обязательных полей автор запрашивает уточнение с перечнем недостающих полей. До уточнения пакет не выдаётся (`BDD06`, п. 5).

<a id="instruction-conflict"></a>
## Конфликт инструкций

Если корневая инструкция разрешает проект `P1`, а вложенная требует экспорт в `P2`, результатом становится `OUTCOME_NONE_CLARIFICATION`. Экспорт приостанавливается до уточнения (`BDD07`, п. 18).

<a id="exact-sha-approval"></a>
## Одобрение кандидата

Право запросить слияние не заменяет одобрение точного SHA. Без такого одобрения результатом становится `approval_required`, целевая ветка остаётся без изменений (`BDD08`, п. 17). Приёмка привязана к точному SHA, окончательное решение о слиянии принимает оператор. [Процесс разработки](../processes/development.md) и [смысловое ядро](../core.md).
